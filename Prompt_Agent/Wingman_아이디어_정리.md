# Wingman

## AI 에이전트를 위한 의도 기반 채팅 자동완성 인터페이스

### Bringing VS Code-Style Autocomplete to AI Chat

---

## 1. 제안 배경

VS Code와 같은 현대 개발 환경에서는 사용자가 코드를 모두 직접 입력하지 않는다.

개발자가 일부만 입력하면 시스템이 현재 코드 문맥을 분석하여 다음에 작성할 코드를 예측하고 자동완성한다.

예시 흐름:

사용자 입력: def login

자동 추천: 이후 코드 미리 표시

Tab 입력: 자동 적용

이러한 방식은 개발자의 입력 부담을 줄이고 생산성을 높였다.

그러나 최근 AI 에이전트 기반 작업 환경에서는 새로운 문제가 나타나고 있다.

사용자는 더 이상 코드를 작성하지 않지만, 대신 AI에게 전달할 명령을 직접 작성해야 한다.

즉, 코드 입력 부담이 프롬프트 입력 부담으로 이동하였다.

---

## 2. 문제 정의

현재 AI 채팅 인터페이스는 대부분 완성된 입력을 전제로 한다.

사용자는 원하는 결과를 얻기 위해 긴 설명을 직접 입력해야 한다.

예시:

사용자 입력: SwiftUI 로그인

실제 의도:
- Apple 로그인
- Firebase 인증
- 상태 관리
- MVVM 구조
- 테스트 고려

하지만 현재 시스템은 사용자가 이를 모두 입력해야 한다.

즉, AI는 결과 생성은 잘하지만 입력 생성은 충분히 지원하지 못한다.

---

## 3. 제안 아이디어

Wingman은 VS Code의 코드 자동완성처럼 AI 채팅 입력창 자체를 자동완성하는 인터페이스이다.

핵심은 단순 문자열 예측이 아니라, 현재 입력과 사용자의 목적을 함께 분석하여 다음 입력을 제안하는 것이다.

사용자는 Tab 키를 눌러 추천 입력을 즉시 적용할 수 있다.

---

## 4. 동작 방식

기존 방식:

사용자

-> 채팅 입력

-> AI

-> 결과

제안 방식:

사용자

-> 채팅 입력

-> Wingman
- 문맥 분석
- 의도 해석
- 다음 입력 예측

-> 자동완성 표시

-> Tab

-> AI 실행

즉, AI 실행 이전 단계에서 입력 품질을 선제적으로 끌어올린다.

---

## 5. 사용 예시

예시 1

입력: 쇼핑몰

자동완성 제안:
Flutter 기반 쇼핑몰 앱 개발. Firebase 사용. 로그인 및 결제 기능 포함.

Tab

-> 입력 완료

예시 2

입력: 회귀분석

자동완성 제안:
Python 구현 및 시각화 추가

예시 3

입력: 로그인

프로젝트 감지: SwiftUI

자동완성 제안:
Apple Sign-In 구현

## 6. 핵심 기능

### 6-1. Intent-Aware Completion

사용자의 표면 입력 뒤에 있는 실제 목표를 추론하여, 누락된 요구사항을 보완한다.

### 6-2. Context-Aware Completion

현재 작업 환경(프로젝트 언어, 프레임워크, 파일 컨텍스트)을 반영해 제안 정확도를 높인다.

### 6-3. Inline Chat Completion

채팅 입력창 내부에서 실시간으로 자동완성을 제공해 입력 흐름을 끊지 않는다.

### 6-4. One-Key Execution

Tab 한 번으로 제안을 적용해 즉시 실행 가능한 프롬프트를 완성한다.

---

## 7. 기존 시스템과의 차이

VS Code 자동완성:

코드 자동완성

-> 다음 코드 예측

Wingman 자동완성:

채팅 자동완성

-> 다음 명령 예측

-> 작업 의도 보완

즉, 코드 자동완성에서 명령 자동완성으로 입력 패러다임을 확장하는 제안이다.

---

## 8. 기대 효과

사용자는 더 이상 AI용 문장을 길게 고민하지 않아도 된다.

원하는 작업을 짧게 입력하면 시스템이 그 의도를 확장하고 완성한다.

AI 시대의 생산성 축은 단순 생성 능력에서 입력 효율로 이동하고 있으며, Wingman은 이 입력 경험을 개선하는 인터페이스를 목표로 한다.

---

## 9. 요약 제언

Wingman은 결과 생성 단계가 아닌 입력 설계 단계에서 생산성을 높이는 접근이다.

핵심 가치는 다음 3가지다.
- 짧은 입력으로도 의도 보완 가능
- 실행 전 프롬프트 품질 자동 향상
- 사용자의 입력 피로와 시행착오 감소

향후 MVP를 기획한다면, Intent-Aware Completion과 Context-Aware Completion을 우선 구현해 사용자 체감 효과를 빠르게 검증하는 전략이 유효하다.
